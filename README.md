
# VolunteerHub

VolunteerHub is a web application for managing and participating in volunteer events.

## Project Structure

- `backend/` — Node.js/Express REST API for authentication, events, users, posts, and registrations.
- `frontend/` — React + Vite app for the user interface.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Backend Setup
```bash
cd backend
npm install
npm run dev
```
The backend will start on [http://localhost:4000](http://localhost:5000) by default.

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
The frontend will start on [http://localhost:3000](http://localhost:3000) by default.

## Features
- User authentication (JWT)
- Event creation, registration, and management
- Admin dashboard for managing users and events
- Posts, comments, and notifications

## Development
You can run both backend and frontend concurrently in separate terminals.
